💾 数据自动保存与本地备份保障
✅ 实时防丢机制： 你的所有修改（任务、习惯、日记、复盘、话术、英语学习笔记等）均会在操作发生瞬间自动写入本地存储（LocalStorage）。
✅ 后台自动快照： 系统每隔 10 秒自动更新云端/本地镜像快照，即使突然关闭浏览器或刷新页面，数据也不会丢失。
✅ 手动全量导出： 建议每周导出一次 `.json` 备份文件，以便在更换设备时一键迁移。
⚙️ AI 接口配置（关联主流公开引擎）
切换引擎会自动填入默认 Base URL 与模型，可修改；选「自定义引擎」可接入任意兼容 OpenAI 接口的网关。部署到 Netlify 后会自动启用同源反代，DeepSeek 等官方 API 可直接在浏览器直连成功，无需填写下方代理；若部署在其他环境且浏览器提示跨域(CORS)失败，再填写「代理/反代地址」或改用 OpenRouter / Groq / 本地 Ollama 等支持跨域的引擎。
